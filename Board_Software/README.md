# Board Software

The microcontroller on the lab kit board is a Seeed Studio XIAO SAMD21 running an Arduino program. The Arduino code is in this folder.

Students do not need this because the board comes already programmed. But the curious student may be interested in examining the Arduino code.

## Viewing or downloading the Arduino code

The Arduino code is the file **ard_pid_v02.ino**.

- **To view it:** Click **ard_pid_v02.ino** in the file list above. The code opens in your browser.
- **To download it:** After opening the file, click the **Download raw file** button at the top right of the code. It's a small down-arrow icon. Hover over it to see its name.

## Opening the code in the Arduino IDE

When you open `ard_pid_v02.ino` in the Arduino IDE, the IDE may say the file must be inside a folder of the same name, and offer to create it. Click **OK**. This is normal for Arduino files.
