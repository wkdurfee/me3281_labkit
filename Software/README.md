# Lab Kit Software

The lab kit application runs on your laptop and controls the lab kit hardware. It comes in two forms. Download the one that fits your computer:

| Download | Use it if | How to run it |
|---|---|---|
| **[labkit_pid.exe](https://github.com/wkdurfee/me3281_labkit/releases/latest/download/labkit_pid.exe)** | You have a Windows laptop | Double-click to run. No other software needed. |
| **[labkit_pid.py](https://github.com/wkdurfee/me3281_labkit/releases/latest/download/labkit_pid.py)** | You have a Mac, or you prefer to run the Python source file | Run it in a Python environment, such as Thonny. Requires the pyserial and matplotlib packages. |

Both links always download the newest version. For step-by-step instructions, see "Installing the Software" in the **[User Guide](https://docs.google.com/document/d/1oedQPF3KCfcU4NCRRZGlrVdvtryyQlVAax1uANhdr_o/preview)**.

## Which version do I have?

The version number appears in the application's window title bar, for example "LabKit PID Control, ver. 2.02."

## Past versions

Every version is on the **[Releases page](https://github.com/wkdurfee/me3281_labkit/releases)**, newest first, with a note on what changed. To download a past version, find it on that page, click **Assets** under it, and click the file you want.

On the Releases page, ignore the "Source code (zip)" and "Source code (tar.gz)" files. GitHub adds those automatically, and they do not contain the application.
